Ohm's Law and Power Calculator

What it does

This is a Python program that calculates voltage, current, resistance, and electrical power using Ohm's Law formulas. It allows users to select what they want to calculate and enter the known values.

How to run it

Install Python 3 and run the following command:

"python ohms_law.py"

Sample output

OHM'S LAW AND POWER CALCULATOR

Enter current: 2
Enter resistance: 5

Voltage = 10 V

My own twist

I added a calculation history feature that allows users to keep track of their previous calculations. I also included input validation to handle incorrect entries.

I learned how to use Python functions, loops, conditional statements, lists, and error handling to build a practical engineering calculator.
